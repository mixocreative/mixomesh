- **SSAO import-freeze fix (2026-06-13, follow-up):** two ~80k-tri GLBs with a 4096² base-colour texture froze on import. Root cause = the SSAO2 pipeline shipped default-ON the same day: its geometry prePass re-renders ALL scene geometry into MRT (color/normal/depth) targets every frame, pushing worst-frame from ~24 ms to ~250–330 ms on those meshes (measured in SwiftShader) — recurring stalls that read as a frozen import and can wedge a TDR-prone GPU/driver (this machine's Chrome 149). Fix: SSAO now defaults OFF (still toggleable in Scene ▸ Environment ▸ Ambient occlusion); the custom selection-mask RTT also sets `noPrePassRenderer = true` so the prePass never double-renders geometry into it. Verified: both models import at ~20 ms worst-frame with SSAO off; browser smoke still exercises the SSAO enable/disable toggle.
- **Heavy-asset perf wave (2026-06-13, follow-up to SSAO fix):** profiled the real workflow (lots of 4096²-textured, 80k+ tri print models) with a headless import benchmark. Findings + fixes: (1) **Validation was the one true main-thread block on import** — ~450 ms of weld + non-manifold edge-map per 80k-tri mesh, run as a microtask. Moved topology to a Web Worker (`workers/MeshValidate.worker.js` + `ValidateWorker.js` client; `MeshValidator._topology` posts a copy of positions/indices, awaits counts; inline fallback for no-Worker). Worker uses numeric packed keys (no string churn) and **signed-volume inverted-normals** replacing the old 64-ray O(tris)-per-ray heuristic. Measured ~450 ms → ~12 ms wall, UI never blocks. (2) **Selection-outline pass + mask RTT ran every frame even with nothing selected** (64-tap fullscreen pass, real cost at 4K) — now detached when the selection is empty, re-attached on first selection (`SelectionOutline._setOutlineEnabled`; browser smoke pins it). (3) **Adaptive resolution** (`scene/AdaptiveResolution.js`): replaced raw `adaptToDeviceRatio` with a capped effective-DPR (≤1.5) base + a safety-valve dynamic downscale (rolling avg frame-time > 45 ms sheds pixels, < 28 ms recovers) — cuts fragment cost for high-DPI users on heavy textured scenes; exports use their own RTT size so output quality is unaffected. Deliberately NOT done: silent texture downscale (export reads pixels from the live GPU texture → would break the LOCKED Mimaki full-res requirement) and static-mesh/material freezing (fights the gizmo + ShaderLibrary edit paths; CPU isn't the bottleneck at realistic mesh counts — GPU/VRAM is). Note: VRAM for N unique 4096² textures is bounded by the export-fidelity requirement; a safe viewport texture cap needs the export path to re-read from source bytes first (future work). All headless tests + browser smoke + export smoke green.
