# MIXOMESH

Browser-based 3D assembly and diorama planning tool. Babylon.js, no build step.

## Run
Serve the directory over HTTP (required for ES modules and WASM):
npx http-server -p 8888 -c-1
Then open http://localhost:8888 in Chrome.
